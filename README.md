# Convite de Casamento

Projeto do fdevs htm e css 

Esse é um projeto que eu fiz para praticar HTML, CSS e um pouco de JavaScript. É um convite de casamento digital, com várias páginas e funcionalidades.

Ainda estou aprendendo, então tem algumas coisas que podem ser melhoradas, mas estou feliz com o resultado até aqui.

## O que tem no projeto

- **Página inicial:** Uma capa com foto, os nomes do casal e a data.
- **Conheça o casal:** Fotos e uma breve descrição dos noivos.
- **Detalhes do evento:** Cards com informações da cerimônia e do cortejo.
- **Contagem regressiva:** Um contador que mostra quanto tempo falta para o casamento (feito com JavaScript).
- **Nossa história:** Uma página com um layout de texto e foto.
- **Galeria:** Um mural de fotos do casal.
- **Dicas de presentes:** Uma lista de sugestões para quem não sabe o que dar.
- **Confirmar presença:** Um formulário onde a pessoa coloca o nome e quantos acompanhantes vai levar.

## Tecnologias que usei

- **HTML:** Para fazer a estrutura das páginas.
- **CSS:** Para estilizar tudo. Usei Flexbox e Grid para fazer os layouts, e também Media Queries para deixar responsivo (funcionar no celular e no computador).
- **JavaScript:** Usei para fazer a contagem regressiva e para a interação do formulário de confirmação.
- **Google Fonts:** Usei as fontes Playfair Display, Montserrat e Great Vibes.
